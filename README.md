# Hotel Booking Demand Analysis

## Project Overview

This project analyzes hotel booking data to understand booking patterns, room prices, and booking cancellations. The analysis uses the Hotel Booking Demand dataset and applies data preprocessing, exploratory data analysis (EDA), and statistical hypothesis testing.

## Dataset

The project uses `hotel_bookings.csv`, which contains hotel booking records and information such as lead time, length of stay, average daily rate (ADR), customer details, and booking cancellation status.

Place the dataset in the same folder as the Jupyter Notebook before running the analysis.

## Project Contents

- **Jupyter Notebook:** Contains data preprocessing, exploratory data analysis, visualizations, and statistical hypothesis tests.
- **Dataset:** `hotel_bookings.csv`
- **README.md:** Instructions for setting up and running the project.

## Requirements

The project uses Python and the following libraries:

- NumPy
- Pandas
- SciPy
- Matplotlib
- Seaborn
- Missingno
- Statsmodels

## How to Run

1. Download or clone this repository to your computer.
2. Make sure Python and Jupyter Notebook or JupyterLab are installed.
3. Install the required libraries by running the following command in your terminal:
    - pip install numpy pandas scipy matplotlib seaborn missingno statsmodels jupyter
4. Place `hotel_bookings.csv` in the same folder as the notebook.
5. Open the Jupyter Notebook.
6. Run all notebook cells in order, from top to bottom.

## Notes

Make sure the dataset filename and file path match those used in the notebook.
